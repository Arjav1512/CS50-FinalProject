🔗 Notion Integration

Used only when you click Export to Notion in the popup. Export creates one page with today's summary in the database below. The page title goes into the database's title column (for a new database that is "Name"); "Date" and "Productivity Score" are filled only if your database has properties with those names.

Create an internal integration at Notion Integrations, then share your database with it (••• → Connections).
Paste the database URL or the 32-character ID from it.

✨ AI Summaries (Google Gemini)

Off by default. When on, the popup's Summarize this page button sends the text of the current tab (up to 3,000 characters, only when you click it) to Google Gemini. Excluded domains are never summarized.

Get a key at Google AI Studio. It is stored only in this browser (chrome.storage.local) and sent only to Google, in a request header.
